# Navratri Stall POS

Simple sale app. Files:
- index.html  -> the whole app (edit the EASY SETTINGS block at the top of the script)
- manifest.webmanifest -> app name/colour for home screen install
- sw.js -> offline support
- icon-192.png, icon-512.png, apple-touch-icon.png -> app icons
- vercel.json -> hosting setting (leave as is)

Deploy: upload all files to a GitHub repo, import the repo in Vercel (Framework: Other).
